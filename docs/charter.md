# Project Charter

## Problem statement
Users with a stuck or faulty modifier key (or motor impairments causing
unintended key presses) trigger accidental browser actions and complete
tasks more slowly. OS features like Sticky Keys help with holding keys
but don't solve a key that is falsely held down.

## Aim
Design and evaluate a Chrome extension that neutralises unwanted modifier
input and offers an on-screen alternative.

## Research questions
- RQ1: Does the extension reduce error rate when a modifier is stuck?
- RQ2: Does it reduce time on task?
- RQ3: Do users find it usable (SUS of 68 or above)?

## Success criteria (to refine later)
- Meaningfully fewer errors than the no-extension baseline
- Time on task not worse than baseline
- SUS above 68

## Out of scope
OS-level fixes, other browsers, mobile, overriding browser-reserved shortcuts.
