# Adaptive Key Extension

A Chrome extension that helps users who have a stuck or unreliable
modifier key (Ctrl, Shift, Alt) by neutralising unwanted input and
providing an on-screen alternative.

This is an HCI project: it includes the design, implementation, and a
user evaluation measuring time on task, error rate, and SUS score.

## How to run
1. Clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the project folder.
